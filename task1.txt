ans:variable is a container used to store data values.

What are the three keywords used to create variables?
ans: var,let,const

Write the syntax to create a variable using var.
ans:var variableName=value;

Write the syntax to create a variable using let.
ans:let variableName=value;

Write the syntax to create a variable using const.
ans:const variableName=Value;

What is declaration?
ans: Declaration means creating a variable without assigning a value.
eg: let age;

What is initialization?
ans:Initialization means assigning a value to a variable for the first time.
eg: let age=25;

What is reassignment?
Reassignment means changing the value of an existing variable.
eg: let age=25;
age=30;

What is redeclaration?
Redeclaration means declaring the same variable again in the same scope.
eg: var x=10;
var x=20;

Which keyword allows redeclaration?
ans:var

Which keyword allows reassignment?
ans:var and let

Which keyword requires initialization when declared?
ans:const
eg:const age=25;

ans:console.warn() is used to display warning messages in the browser console.
